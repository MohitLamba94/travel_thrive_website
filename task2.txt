You are an award-winning UI/UX designer, creative director, and senior frontend engineer.

Design and build a premium, modern, static, responsive website for **Travel Thrive** using only HTML, CSS, and JavaScript.

Imagine this website is launching in 2026 and must compete visually with premium travel brands.

The final result should feel like a modern luxury travel company rather than a traditional travel agency.

## Objective

Design a premium, static website using only HTML, CSS, and JavaScript.

Requirements:

* No backend
* No database
* No login
* No booking engine
* No form submissions
* No API calls

Everything must be deployable as static files.

Clickable phone numbers, email links, WhatsApp links, and Google Maps embeds are allowed.

## Design Philosophy

Approach this project as if you are designing a completely new premium travel brand from scratch.

Think beyond common travel agency templates.

Create a distinctive visual identity with thoughtful layouts, refined typography, elegant spacing, and premium interactions.

Every section should feel intentionally designed while remaining part of one cohesive design system.

## Creative Direction

Aim for a blend of:

* Luxury hospitality
* Editorial magazine
* Modern product design
* Premium tourism branding

Take inspiration from the overall design quality of:

* Airbnb
* Aman Resorts
* Black Tomato
* Audley Travel
* Travelive
* Booking.com (information hierarchy only)
* Expedia (service presentation only)

Do **not** copy any of these websites.

Use them only as inspiration for layout quality, typography, spacing, visual hierarchy, and interaction design.

## Visual Style

Use:

* Oversized typography
* Large immersive photography
* Editorial-inspired layouts
* Asymmetrical compositions where appropriate
* Subtle glassmorphism only if tasteful
* Layered cards
* Soft shadows
* Rounded corners
* Elegant gradients
* Generous whitespace
* Premium iconography
* Smooth scroll animations
* Tasteful parallax
* Refined hover effects
* High-quality travel imagery

The overall aesthetic should feel calm, premium, and trustworthy.

## Color Palette

Create a sophisticated palette inspired by luxury travel.

Suggested tones:

* Warm White
* Sand
* Deep Navy
* Forest Green
* Soft Gold accents
* Charcoal
* Muted Blue

Avoid loud colors and flashy gradients.

## Typography

Use modern Google Fonts.

Pair one display font with one clean sans-serif font.

Emphasize:

* Large headlines
* Comfortable reading width
* Strong visual hierarchy
* Excellent spacing
* Editorial rhythm

## UX Goals

Within the first few seconds, visitors should clearly understand:

* Who Travel Thrive is
* What services the company provides
* Why the company is trustworthy
* How to contact the company

Every section should naturally guide visitors toward getting in touch.

* ARIA labels
* Keyboard navigation

* Lightweight code
* Optimized CSS
* Reusable utility classes
* Modular structure
* SEO-friendly semantic markup
* Easy to maintain and edit
